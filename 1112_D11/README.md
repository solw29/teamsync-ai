### 대안과 선택 근거

LLM Review를 UI 모델로 그대로 쓰기보다 실행 metadata와 상태를 가진 별도 계약을 택했다. LLM 스키마와 화면 변경의 결합을 줄일 수 있다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
