# D18 — 평가 화면

React 확장 계획상의 11월 19일 일정입니다. 실제 구현·검증 작업은 2026-11-12에 수행했으며 미래 날짜에 완료했다고 소급 주장하지 않습니다.

구현: 실측 통계·표·Bar Chart.

최신 검증과 미완료 범위는 [통합 검증 기록](../docs/react-test-report.md)을 확인하세요. D20 외부 배포와 사람 시연은 별도입니다. 기존 D1~D10 기록과 파이프라인은 유지합니다.

## 구현 판단과 완료 기준 검토 (2026-11-23)

### 작업

실측 평가를 시각화한다.

### 완료 기준과 실제 달성

완료 기준: 분모·표본·양쪽 결과를 표시하고 임의 정확도/비용을 생성하지 않아야 한다.

실제 상태: 과거 결과 표시 검증. 일반 정확도 주장 없음.

### 구현 방법

실제 summary에서 카드·bar chart·PR 비교표를 파생한다.

### 대안과 선택 근거

복잡한 chart 엔진 대신 단순 CSS bar를 택했다. 적은 고정 범주의 분포를 보여주는 데 추가 상태/의존성이 필요하지 않았다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

통과율과 검출률 혼동 위험이 있어 문법·환경 오류 없이 실행과 수정 코드 통과, 버그 실패/수정 통과를 따로 표기했다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
