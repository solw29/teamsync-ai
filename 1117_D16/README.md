### 대안과 선택 근거

원문 HTML 렌더링 대신 React 텍스트를 택했다. 지적은 외부 데이터이므로 스크립트 실행 없이 읽혀야 한다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

실제 평가에서 위치는 유효해도 오탐이 있었다. 위치 확인을 실제 문제 확인으로 표시하지 않고 unreviewed를 유지했다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
