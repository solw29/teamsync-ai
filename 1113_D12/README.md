React 확장 계획상의 11월 13일 일정입니다. 실제 구현·검증 작업은 2026-11-12에 수행했으며 미래 날짜에 완료했다고 소급 주장하지 않습니다.

최신 검증과 미완료 범위는 [통합 검증 기록](../docs/react-test-report.md)을 확인하세요. D20 외부 배포와 사람 시연은 별도입니다. 기존 D1~D10 기록과 파이프라인은 유지합니다.

## 구현 판단과 완료 기준 검토 (2026-11-23)

### 작업

Python 결과를 웹 JSON으로 내보낸다.

### 완료 기준과 실제 달성

완료 기준: 실제 보존 결과12개가 검증 가능한 JSON이 되고 공개 예제에는 민감 원문이 없어야 한다.

실제 상태: 기존 변환·익명화 검증. 원시 GitHub artifact 수집 서버는 3차 대상.

### 구현 방법

export_report.py로 D6 evidence를 변환하고 --public에서 코드·repo·SHA·링크를 제거했다.

### 대안과 선택 근거

브라우저에 GitHub 토큰을 넣는 직접 API 방식 대신 정적 결과 파일을 택해 초기 서버와 credential 관리 부담을 줄였다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

초기 Exporter는 보존된 D6 자료 전용이라 새 실행 결과를 자동 수집하지 못했다. 이 한계를 명시하고 D36/D37에 run별 report/manifest를 추가했다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
