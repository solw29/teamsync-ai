# D19 — 통합 검증

React 확장 계획상의 11월 20일 일정입니다. 실제 구현·검증 작업은 2026-11-12에 수행했으며 미래 날짜에 완료했다고 소급 주장하지 않습니다.

구현: web/e2e/smoke.py, docs/react-test-report.md.

최신 검증과 미완료 범위는 [통합 검증 기록](../docs/react-test-report.md)을 확인하세요. D20 외부 배포와 사람 시연은 별도입니다. 기존 D1~D10 기록과 파이프라인은 유지합니다.

## 구현 판단과 완료 기준 검토 (2026-11-23)

### 작업

브라우저·반응형·오류 흐름을 검증한다.

### 완료 기준과 실제 달성

완료 기준: 실제 import→탐색·잘못된 JSON·empty·재시도·모바일·copy·링크가 재현돼야 한다.

실제 상태: 자동화한 핵심 흐름 통과. 모든 브라우저·접근성 조합 검증은 아님.

### 구현 방법

Vitest/RTL과 Python Playwright smoke를 병행했다.

### 대안과 선택 근거

단위 테스트만으로 브라우저 clipboard/파일 import/overflow를 입증할 수 없어 실제 Chromium 검증을 추가했다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

중첩 상태 테스트에서 파일이 잘못돼도 기존 데이터를 유지해야 했다. 파싱 완료 후 원자적으로 교체하고 실패 alert/재시도를 검증했다. 전체 접근성 인증은 수행하지 않았다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
