# D14 — Dashboard

React 확장 계획상의 11월 15일 일정입니다. 실제 구현·검증 작업은 2026-11-12에 수행했으며 미래 날짜에 완료했다고 소급 주장하지 않습니다.

구현: 검색·필터·정렬·빈 상태.

최신 검증과 미완료 범위는 [통합 검증 기록](../docs/react-test-report.md)을 확인하세요. D20 외부 배포와 사람 시연은 별도입니다. 기존 D1~D10 기록과 파이프라인은 유지합니다.

## 구현 판단과 완료 기준 검토 (2026-11-23)

### 작업

PR 목록 탐색을 구현한다.

### 완료 기준과 실제 달성

완료 기준: 제목/번호/repo 검색, 상태 필터, 날짜/지적 수 정렬과 빈 상태가 일관돼야 한다.

실제 상태: 파일 모드 기능 검증. 대규모 이력 성능을 측정한 것은 아니다.

### 구현 방법

Dashboard가 검증된 bundle에서 통계와 목록을 파생하고 RTL/브라우저에서 검색·정렬을 검증한다.

### 대안과 선택 근거

서버 쿼리보다 초기 파일 bundle의 클라이언트 필터를 택해 별도 API 없이 동작하게 했다. 큰 이력은 3차 cursor API로 전환한다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

수정 버전인데 전체 Failed로 보이는 데이터가 있었다. 실제 Ruff I001이 남았기 때문이어서 숫자를 임의 수정하지 않고 pytest와 전체 상태를 구분했다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
