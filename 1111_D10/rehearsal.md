# 최종 리허설 (실행 기록 대기)

- [ ] ruff·pytest 통과
- [ ] 동일 저장소 PR 생성·갱신 시 실행, fork·draft 제외
- [ ] AI 이전 검사 댓글 표시 및 동일 댓글 최종 갱신
- [ ] 실제 diff 밖의 지적 제외, 생략 표시
- [ ] 생성 초안 실행 상태와 자동 커밋 없음 확인
- [ ] LLM 키 누락·오류, 테스트 실패, 환경 오류 구분
- [ ] Discord 도착 및 실패 상태 표시

- [ ] 백업 영상 재생 확인
- [ ] workflow 변경 리뷰 및 시크릿 분리 확인

실행일(KST): 미실행 / PR 링크: 미기록 / 소요 시간: 미측정 / 문제 및 복구: 미기록

오류가 나면 Actions의 실패 잡과 공개 가능한 상태만 확인합니다. 시크릿을 로그에 출력하지 않습니다. 모델 장애 시 검사 댓글을 사용하고, Discord 장애 시 PR 링크로 직접 안내합니다. 리허설에서는 새 기능을 추가하지 않습니다.
