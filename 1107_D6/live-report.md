## 재현과 증거

`evaluation.csv`는 사례별 링크와 판정입니다. `live-evidence/`에는 분석 JSON, diff, 검사 요약, 생성 테스트 상태, 댓글·run 메타데이터, 동일 초안의 양쪽 실행 결과와 `summary.json`을 보존했습니다. GitHub artifact 만료 후에도 이 측정값과 모델 코드를 확인할 수 있습니다. 원본 Actions URL은 각 `publication.json`에 있습니다.

동일 초안 평가 workflow는 `.github/workflows/evaluate-pair.yml`입니다. 한 buggy PR의 analysis artifact를 내려받아 별도 시크릿 없는 runner에서 양쪽 SHA의 코드에 그대로 실행했습니다. 서로 다른 모델 출력끼리 비교하지 않았습니다. `analysis_sha256`으로 비교 대상을 고정했습니다.

## 발견한 문제와 수정

첫 S01 실행은 모델이 import를 누락했습니다. 이를 검출 성공으로 계산하지 않고 standalone import 지시와 NameError 환경 오류 분류를 보완했습니다. 첫 실행은 이번 30개 결과에서 제외했습니다. 이후 S01 재실행을 평가에 사용했습니다.

S02·S03·S04·S06에서 모델이 구현의 버그 동작을 정답으로 학습한 듯한 기대값이 관찰됐습니다. 예를 들어 S02는 음수에 None을 반환해야 하는데 음수를 그대로 기대하고, S04는 범위 밖 할인율을 허용하는 값을 기대했습니다. 평가 후 프롬프트에 계약·기대 동작을 현재 구현보다 우선하고 결함 회귀 테스트를 먼저 만들라는 지침을 추가했습니다. **이 추가 지침의 개선 효과는 아직 재측정하지 않았습니다.**

## 실험 제한

- 수정 버전은 사전 정의한 기능 버그를 수정한 뜻입니다. S01 buggy를 제외한 fixture 테스트 11개에는 공백으로 인한 실제 Ruff I001이 있습니다. 실제 lint 지적 5건은 오탐으로 세지 않았습니다. 기능 검출과 lint 잡음이 함께 있는 실험이므로, 다음 회차에는 fixture 서식을 정리하고 재측정해야 합니다.
- 오탐과 버그 지적 판정은 이번 작업에서 코드와 계약을 대조한 결과이며 독립된 사람의 평가가 아닙니다.
- 저장소는 현재 공개 상태입니다. 합성 코드만 사용했으며 fork 제외·신뢰 가능한 동일 저장소 쓰기 사용자라는 제한이 있습니다. 외부 기여자 코드를 시크릿과 함께 실행하는 운영으로 확장하지 않습니다. 저장소 가시성·권한은 변경하지 않았습니다.
- D7~D8 일정 조율은 진행하지 않습니다. 생성 테스트 품질과 평가 신뢰성을 먼저 개선합니다.
