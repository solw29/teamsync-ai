### 대안과 선택 근거

실행 버튼이나 자동 적용 대신 조회·복사만 제공해 프런트엔드에서 임의 Python 실행을 만들지 않았다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

실제 브라우저의 clipboard 권한이 테스트 조건이었다. 권한을 명시하고 읽어 온 문자열까지 검증했으며 실패 시 수동 복사 안내를 둔다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
