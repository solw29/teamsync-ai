### 대안과 선택 근거

모의 UI 편집 영상보다 실제 GitHub와 React 화면을 택해 관측 결과를 보존했다. 중간 컷/배속 없이 한 번의 탐색으로 연결했다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

Chromium 인증서 오류와 과도한 CA 등록의 자동 승인 거절이 있었다. 필요한 환경 CA를 검증한 범위/실행기로 좁혀 TLS 검증을 유지했다. 첫 화면을 README 목적 설명으로 개선해 전체를 다시 녹화했다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
