과거 숫자를 덮어쓰기보다 불변 기준선을 택해 새 결과가 무엇을 바꿨는지 추적하게 했다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

새 임시 artifact의 test 파일이 수집돼 테스트 수가 부풀었다. pyproject testpaths를 명시해 추적된 테스트만 기준으로 집계했다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
