### 대안과 선택 근거

Discord Bot/서버/SQLite를 늘리는 대신 C 계획의 축소 규칙을 적용했다. 핵심 검증 품질이 먼저라는 판단이며 일정 추천 성능 비교 실험은 하지 않았다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

필수 실증이 늦어져 선택 기능을 착수하지 않았다. 결정을 기록하고 미구현을 완료처럼 표시하지 않았다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
