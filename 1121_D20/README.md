최신 검증과 미완료 범위는 [통합 검증 기록](../docs/react-test-report.md)을 확인하세요. D20 외부 배포와 사람 시연은 별도입니다. 기존 D1~D10 기록과 파이프라인은 유지합니다.

## 구현 판단과 완료 기준 검토 (2026-11-23)

### 작업

배포 준비·문서·시연을 정리한다.

### 완료 기준과 실제 달성

완료 기준: 정적 build·사용법·시연·외부 배포 여부를 분리하고 배포 시 실제 URL을 검증해야 한다.

실제 상태: 빌드·문서·영상 완료, 외부 배포/사람 발표 미완료.

### 구현 방법

Vercel rewrite, web README, 별도 build artifact workflow와 실제 영상으로 준비했다.

### 대안과 선택 근거

상태 없는 정적 호스팅을 택해 초기 DB/서버 운영을 피했다. 데이터는 import하므로 LLM 키를 배포할 이유가 없다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

배포 계정/대상 확정이 없어 외부 게시를 실행하지 않았다. 빌드 artifact를 배포 URL처럼 제시하지 않았다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
