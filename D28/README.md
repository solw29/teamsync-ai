# D28 — 선택 Notebook 실행

실제 작업일: 2026-11-22 (KST). 날짜 없는 D번호 폴더로 기록합니다.

## 작업과 상태

문서의 축소 규칙에 따라 Notebook 자동 실행은 구현·실행하지 않았습니다. 기존 PR 코드의 실행 영역을 확대하지 않습니다.

현재 상태: **선택 기능 미실행**.

관련 파일: `docs/phase2/README.md`.

## 재현·증거

공통 명령: `python -m pytest -q`, `ruff check .`, `npm --prefix web test`, `npm --prefix web run build`. 관련 테스트는 `tests/phase2/`, 브라우저 검증은 `web/e2e/phase2_smoke.py`입니다.

[설계·범위](../docs/phase2/README.md)와 [실행 명령·결과·미검증](../docs/phase2/validation.md)을 확인하세요. 계획상의 완료 기준과 실제 결과를 혼동하지 않습니다. 다음 차수는 자동 진행하지 않습니다.

## 구현 판단과 완료 기준 검토 (2026-11-23)

### 작업

Notebook 자동 실행의 착수 여부를 결정한다.

### 완료 기준과 실제 달성

완료 기준: 선택 범위·비활성 이유·미검증을 기록하고 다른 필수 작업을 막지 않아야 한다.

실제 상태: 선택 항목 미구현/미실행.

### 구현 방법

자동 커널 실행을 추가하지 않고 not_run으로 남겼다.

### 대안과 선택 근거

nbclient/서버 커널을 추가할 수도 있으나 실행 비용·dependency·격리 범위가 커진다. 문서의 선택 기능 축소 규칙을 적용했다. 이는 현재 코드와 기록을 대조한 설계 판단이며, 수행하지 않은 대안 간 성능 비교 실험을 뜻하지 않습니다.

### 개발 중 문제·해결·남은 한계

구현 장애를 해결한 항목이 아니라 의도적으로 미착수한 항목이다. 성공 검증으로 표시하지 않는다.

증거는 이 README의 관련 파일·검증 기록과 연결합니다. 운영 장애 기록이 없는 설계 위험은 실제 운영 장애로 주장하지 않습니다. 숫자는 각 차수의 실행 기록을 따르며, 이전 통과 수를 현재 코드의 새 실적으로 재사용하지 않습니다.
